## 1. Bugs
**High**
1. `js/app.js:5089` runNow — a settings change or Reroll during a running universe chain falls through to the single-file path. It wipes `state.results` and pollutes the chain's shared runner. Fix: ignore/defer while `state.universe.running` (set a rerun-after-chain flag); guard `reroll()` the same way.
2. `js/tournament.js:376-384` — Final Four pairs ff[0]–ff[1] and ff[2]–ff[3]. With the S-curve placing overall #1 East, #2 West, #3 South, #4 Midwest, #1 meets #2 in the semis; the NCAA pairs #1–#4 and #2–#3. `balanceBracket` (l.160-167) can also move 1 seeds between regions. Fix: pair by each region's 1-seed overall rank, and exclude seed line 1 from the balancing swaps. (The S-curve region order comes from the audit pass and was not re-verified.)

**Medium**
3. `js/app.js:3996/4174` readFiles/installFiles — loading files mid-chain swaps `state.files/runners/results` under the chain's callbacks. Refuse or cancel the chain.
4. `js/app.js:5467` rerollUntil — an in-flight search isn't cancelled when files are replaced, and `untilKey()` lacks file fingerprints, so a seed found for the old class is applied to the new class.
5. `js/app.js:333` + `7195-7206` — after the localStorage quota fallback (universe: null), `loadAutosave()` identity check fails, so the IndexedDB universe is never restored. Accept the record when the current universe is empty.
6. `js/news.js:3275-3279` "sophomore leap" — `bestBy`/`slots` take the first S-1 row, which can be the redshirt row with no ppg. That gives NaN, then a `toFixed` TypeError. Use the same predicate as `find`.
7. `js/app.js:10845-10853` — Ctrl+Z/Shift+Z/Y and `?` fire while a modal is open. `?` overwrites `modalOk`. Early-return when the modal is visible.
8. `js/app.js:4553/10231` runBatch uses `effectiveCfg()` instead of `fileCfgFor(state.active) || effectiveCfg()`.

**Low**
9. rerollUntil cancel reports "after 0 tries" on the worker path (`k` isn't updated from `searchProgress`).
10. Search worker error leaves a no-op undo entry (5474/5646) and clears redo.
11. Batch worker is never `terminate()`d on done/error (10065/10238). It leaks the league file in memory.
12. hashchange (10456) clears redo before validating the link.
13. `views.js:2053/5466` — "Show his game log" is offered for players without a gameLog, which leaves the tab blank.
14. `views.js:3975` Import universe — `f.text()` has no catch and bypasses `readTextFile`, so gzipped exports fail silently.

## 3. Settings, solvers, stats, formulas
Issues:
1. Final Four pairing and 1-seed swaps — see §1 items 2.
2. Class pace jitter `Math.max(PACE_MIN, pace+N(0,2.5))` has no ceiling (engine.js:1453, 5023). Use a two-sided clamp.
3. `stats.js:2800` clamps pace to 55-82 after `+scoringEnv*1.6`, so the top of the scoringEnv dial is dead when pace is high.
4. `awards.js:151` shrinks the intercept using the already-shrunk slope, so the fit misses the centroid even at trust=1. Use `a = my - b*mx`.
5. `awards.js:157` residual SD uses `/n`; use `/(n-2)`.
6. `bbgmstats.js:282, 391` — PER/WS report 0 rather than n/a under the 10-minute cutoff; EWA is derived from that 0.
7. League ortg/drtg averages sum all teams but divide by the count with gp>0 (bbgmstats.js:237, 449). Empty teams default to 100 (engine.js:6492) and feed BPM `teamRate`. Treat them as missing.
8. Oliver ratios divide by `t.fta`/`t.oppFta` unguarded (bbgmstats.js:337, 352). NaN is zeroed, so ortg becomes 0.
9. Model usage (stats.js:1679) ignores OT while exported `usgp` uses real minutes, so the two can disagree.
10. VORP defaults `numGames` to 82 when callers omit it (bbgmstats.js:543). Require it at every call site.
11. Enum validation is skipped when the CHOICES fn returns null (era before Calibration loads), so a bogus `cfg.era` persists into the UI.
12. CLAMP uses the slider band (pace ≥58) while jitter can yield 55-58, a value the panel can't show.
13. `ratings.js` classCurve applies the lottery multiplier proportionally, so cliff steepness scales with classQuality. Likely unintended.
14. `ratings.js:3357-3372` — the ovr bisection prefers `lo` on ties, which lands one below target and forces `touchUp`. Prefer `hi`.
15. Blocked-shot rate (engine.js:6458) mixes per-game team averages and season totals. Confirm the zone counts share the same basis.

Verified correct: TS% and the FT_TRIP 0.44 constant; the possession identity; Game Score; PER (VOP, factor, pace, normalized to 15); EWA; AST/BLK/STL/REB/USG%; Oliver ORtg/DRtg; OWS/DWS; BPM 2.0 with the team adjustment; VORP formula; RNG child streams (Math.random is used only for an unspecified seed); all DEFAULTS are used and inside their bands; FILLER_POS weights sum to 1; the balanceBracket swap search restores state; play-in sizing.
