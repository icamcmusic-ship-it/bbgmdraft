# Full audit, 24 September 2026

This covers `main` at commit `ee3f4b9`. Every finding comes from reading the code in this pass, from running `tools/validate.js`, and from Playwright screenshots at 1440px and 390px wide. The earlier README audit sections were not used as sources.

`node tools/test.js` passes all 1049 checks, but the full run takes about 12 minutes. `engine.js`, `stats.js` and `ratings.js` were sampled for bugs, not read in full.

## 2. UI/UX improvements and QOL upgrades

### UI/UX
1. **The mobile header is too tall.** It is sticky and wraps into about five rows (roughly 210 of 844px). Below 560px, unstick it or move Tools, Export and Theme into a "⋯" menu.
2. **The theme picker is in the header** and pushes Export onto a second row. Move it to Settings.
3. **The tab strip overflows on mobile with no cue.** Add edge fades or chevrons, or switch to a `<select>` on narrow screens.
4. **The CLASS/SEASON/UNIVERSE group labels look like tabs** and the bar wraps awkwardly. Use real dividers, or one row per group.
5. **Icon-only buttons** (◎ 🔗 📋 ⚑ 📖 ⌨) rely on `title`, which never appears on touch. Add labels, or show the tooltip on focus.
6. **Undo shows a word but Redo shows ↷.** Make them match, and name the action ("Undo: Class quality").
7. **The empty state** shows a fully live 30-control settings panel. Collapse it until a class is loaded, and make "Try a sample class" the primary button.
8. **The empty-state copy says "drop"** even on touch devices, and it uses inline styles. Change it to "Choose a file (or drop it here)" and make the whole box clickable.
9. **The Draft board intro is long and technical.** Cut it to one line and put the rest in an "About this board" disclosure.
10. **The class chips next to the count are unlabeled** ("not a red flag in the class"). Add a "Class notes:" label.
11. **The Risers/Fallers cards use monospace text that wraps badly.** Use a small grid with ellipsis, and put "Copy as markdown" in the card header.
12. **The Honors column runs past the right edge.** Clamp it to two lines or show a count badge.
13. **Player Edit is hard to find.** Make the toggle more prominent, or add an Edit action to each board row.
14. **Search and the position filter sit below the cards**, off-screen on mobile. Move them above the table and make them sticky with the header row.
15. **Every setting carries "re-runs: … ms" fine print.** Show it only in the Model view or on focus.
16. **The Shape/Season/Model chips are unexplained.** Add a "Show settings about:" label and a hidden count.
17. **The `#ovrMode` option text is cut off.** Shorten it and move the detail into the hint.
18. **Settings groups do not show what changed.** Add a "changed: N" badge to each group's summary.
19. **Name links and "?" buttons are about 14–16px tall.** Raise them to at least 24px (WCAG 2.5.8).
20. **Re-runs of about 200ms give no busy feedback.** Add `aria-busy` and a thin progress bar over `#view`.

### QOL

2. Warn in `beforeunload` when there are locks or edits that have not been exported.
3. Seed pill: show a "Copied" toast and allow editing the seed in place.

5. Player Edit shortcuts: j/k to move, Enter to edit, L to lock. List them in the shortcut sheet.
6. An undo history dropdown for jumping back several steps.

8. A result count ("12 of 70") and a "Clear filters" button when filters leave the table empty.

10. An export button that names the file and year when several classes are loaded.
11. Paste class JSON from the clipboard into the empty state.
12. A floating Settings button on mobile.

## 3. Settings, solvers, stats and formulas

**Verified correct:**
- The OVR formula (`js/bbgm.js:42-76`) matches BBGM: all 15 weights, the intercept of 48.5 and the piecewise fudge.
- The bisection solver and integer touch-up (`ratings.js:3329-3395`).
- PER, ORtg/DRtg, WS, BPM, VORP, EWA and the rate stats (`bbgmstats.js`).
- TS% and possessions (`stats.js`).
- The tournament S-curve and seed order.
- The rankings and awards divide-by-zero guards.

`tools/validate.js` passes every era in about 76s. Fifteen checks pass with no margin left, which makes them fragile: "Stat line reconciles 0.000", BLK big:guard 4.61 against a floor of 4.50, and USG% max 36.6 against a ceiling of 37. 

**Issues:**
1. **`Config.make()` clamps count settings but never rounds them.** `eliteCount: 2.5` survives and `classCurve` (`ratings.js:3406`) treats it as a half-strength third star. Round count keys in the CLAMP loop.
2. **`transferShare` does not deliver its label** (`engine.js:230`, label `app.js:1011`). The year multipliers of 1.1×, 1.65× and 2.2× give about 37%, 56% and 75% at the default of 34. Seniors saturate at 45, so the top half of the 0–90 slider barely does anything. Renormalize the multipliers or relabel the setting.
3. **`freshmanShare` cannot go above about 87%** because of the 0.96 cap and the rank multiplier (`engine.js:199`), even at 100.
4. **Read-site clamps disagree with `CLAMP`.** `seasonEvents` uses 0–20 against 0–14 (`teams.js:1800`), and the award strictness settings use 0.2–3 against 0.4–2 (`awards.js:679-687`). Use `Config.sliderRange()`.
5. **`awardStrictness` has no undefined fallback** (`awards.js:679`), so a config built without `make()` gives NaN slots.
6. **Conference and pro strictness never follow the main dial.** Both default to 1.0, so the `=== undefined` fallback never runs. Default them to `null`, or document them as independent.
7. **Stale fallback default:** `engine.js:141` uses `freshmanShare` 46, but `DEFAULTS` is 32.
8. **`classQuality`, `classDepth` and `eliteCount` do nothing in "preserve" mode.** Grey them out in the panel when that mode is selected.
9. **`archetypePool`'s CLAMP ceiling is hard-coded to 385.** Derive it from the archetype table's length.
10. **VORP is scaled to an 82-game season** (`bbgmstats.js:227`), which understates college seasons. Pass the real schedule length.

## 4. Replayability

1. **Daily seeded challenge:** `seed = "daily-YYYY-MM-DD"`, with goals drawn from the REROLL predicates. `scoreChallenge` (`app.js:5080`) already scores it.
2. **Challenge par and score:** count the settings moved and the reruns, keep a best score per challenge, and put it in the hash.
3. **Challenge campaign:** clearing one challenge unlocks the next. Each tier forbids the dials that solved the previous one.
4. **Prediction mode:** pick the champion, the POY and the No. 1 pick before the season, then get graded on them. The staged runner already pauses between phases.
5. **Bracket pool:** fill in the 68-team bracket before March and score it ESPN-style. The upset factor becomes the difficulty.
6. **Strangeness bingo:** a 3×3 card drawn from the `strangeness().reasons` kinds (`engine.js:4703`).
7. **Short share codes:** base32 of the seed, variation and settings-diff hash, with a paste box.
8. **Blind scout mode:** hide ovr/pot, have the user rank a top 10, and score it against the final board.
9. **Mutators:** stackable named `cfg` patches such as "No bigs", "Chaos March" and "Portal era", shown in the class name.
10. **Achievements ledger:** firsts such as a 16 seed beating a 1 or an unbeaten champion, each stored with its seed so it can be replayed.
11. **Unlockable eras and flavors:** achievements unlock the third era that is already in the table.
12. **"Find the seed" puzzle:** reproduce a given headline set using only three dials.
13. **Ghost rival:** load someone else's result code and compare it on the challenge bar.
14. **Chaos draft:** Surprise me with the anomaly shortlist picked automatically.

## 5. Universe mode

1. **Start a universe from nothing.** Today it requires at least two real files (`app.js:5452`). Generate N consecutive synthetic seasons with `Sample.makeClass`. This is the biggest single unlock.
2. **Performance:** the chain calls a full `render()` every season (`app.js:5660-5674`). Throttle it first, then move the chain into `worker.js`.
3. **"He came back" thread:** build it from registry entries that have `returned` set or honors in more than one season (see the comment at `universe.js:1475`).
4. **Follow a program:** add `u.followed`, highlight its rows on the timeline, lead the paper with it, and add a season-end card.
5. **Dynasty goal mode:** take a low-prestige program to a level or a title in N seasons, within a dial budget.
6. **Pro-career tail:** give each registry entry a seeded pro outcome. This allows a pro-weighted Hall of Fame and a second axis for the records book.
7. **Rivalry heat with decay:** the book never ages (`universe.js:516`). Add a "rivalry renewed" thread.
8. **IndexedDB storage with named save slots**, replacing the capped localStorage copy. This also fixes bug #6.
9. **Deeper news memory:** give each program a digest of its last title, drought length and last POY. This adds "ends the N-year drought" stories.
10. **A detail drawer for each season** built from `u.cfgs[i]`, the season's row and its threads.
11. **Real forward simulation:** replace `extrapolateForward` guesses with synthetic seasons.
12. **Returners who were not drafted** seeded into the next season's `pastRoster` through the registry.
13. **A Coaches records table:** wins, titles, tree size and tenure, plus a hot-seat preview.
14. **Universe-level strangeness:** a "weirdest season" record and a decade summary card.
